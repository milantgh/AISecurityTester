一、项目介绍

AISecurityTest 是一套本地桌面大模型安全红队工具，面向大模型应用、LLM 对话接口、RAG 知识库、Agent/MCP扩展组件开展对抗性安全测试。内置完整 OWASP LLM Top10 (2025) 测试用例库，支持载荷生成、文本混淆变换、AI 改写多候选、多模态恶意样本生成、MCP恶意组件模板、测试报告导出，帮助安全人员、开发人员快速完成AI应用安全验收与红队演练。

运行环境：Python + Tkinter，纯本地程序。

二、核心能力

1. 完整用例库 PI‑001 ~ PI‑040，覆盖 OWASP LLM01‑LLM10 全部风险分类：
   - LLM01 提示注入（直接 / 间接 / 多模态 / Agent 链路 / 编码混淆 / 渐进越狱 Crescendo）
   - LLM02 敏感信息泄露（训练数据记忆 PII 提取）
   - LLM03 供应链风险（推理引擎 CVE、MCP 恶意插件）
   - LLM04 数据与模型投毒（后门触发词、反馈循环污染）
   - LLM05 不当输出处理（SQL/Shell/HTML 输出注入）
   - LLM06 过度代理（Agent 工具越权、最小权限校验）
   - LLM07 系统提示泄露
   - LLM08 向量与嵌入弱点（多租户隔离、知识库投毒）
   - LLM09 幻觉风险（伪造 CVE / 文献 / 包名诱导）
   - LLM10 无界资源消耗（token 耗尽、无限工具调用）
2. 三层载荷生成引擎：载体 × 手法 × 载荷，快速组装各类攻击 prompt
3. 文本变换工具箱：零宽字符、Base64、Hex、Unicode 转义、形近字混淆、ChatML/Llama 标记注入、低资源语言翻译绕过
4. AI 改写模块：对接 OpenAI 兼容接口 / Ollama，多候选改写，保留回执标记，可校验载荷是否丢失
5. 一键流水线：生成 → AI 改写 → 文本变换 → 载荷完整性校验完整链路
6. 多模态恶意样本生成
   - 图片 PNG：白底白字、极小字号、注释隐藏注入文本
   - 音频 WAV：叠加隐藏频段的音频样本
   - PDF：白色字体、页面外、透明文字隐藏 payload
   - CSV：Excel 公式注入样本（DDE、CMD、HYPERLINK、WEBSERVICE 外发）
7. MCP 安全审计模块：恶意 manifest 样例 + MCP 组件静态审查 Checklist
8. 回执标记机制`<<AIST_OK>>`，自动检测经过改写、变换后载荷是否丢失
9. 报告导出：Excel / Word / HTML 测试报告，包含用例 ID、分类、前置条件、步骤、预期结果、防御方案、OWASP 映射
10. 本地历史记录：保存 payload 生成历史，持久化在用户家目录，不上传云端

三、使用流程

基础用例生成流程

1. 左侧侧边栏选择风险分类，选中对应测试用例 ID
2. 点击「生成该用例 Payload」得到攻击测试 prompt
3. 可以复制 / 保存文本，也可以生成图片 / PDF/CSV 多模态样本
4. 将用例加入报告，多条用例收集完毕后，右上角「导出报告」，输出 xlsx/docx/html 测试文档

三层组合生成 payload

1. 左侧点【通用三层组合】
2. 设置生成数量，选择预设载荷或自定义 payload
3. 可勾选是否启用载体、手法，点击生成
4. 使用「检查载荷保留」校验标记 `<<AIST_OK>>` 是否存在

AI改写（需要大模型API）

顺序重要：先AI改写，后文本变换；不要先编码再交给大模型改写，会失去攻击效果

1. 填入 Endpoint、API‑Key、Model，支持 OpenAI 兼容接口、Ollama 本地大模型
2. 填入原始 payload，选择改写风格、候选数量
3. 执行改写，校验载荷标记是否保留
4. 可一键将改写结果送入【文本变换】页面继续混淆处理

一键流水线

自动化链路：用例生成 → AI 改写 → 文本变换 → 载荷校验

1. 选择目标用例 ID，配置生成数量、改写风格、变换方式
2. 点击【运行流水线】
3. 输出原始、改写后、变换后的完整对比结果

MCP 组件安全审计

1. 切换到【MCP恶意模板】页面
2. 查看恶意 manifest 样例，复制保存 json
3. 使用附带的静态审查清单对业务 MCP 插件做安全审计

多模态样本

全部样本仅用于授权安全测试环境，不要对外分发恶意样本。
支持生成 PNG 图片、WAV 音频、PDF、CSV 公式注入测试样本。
